#🥾👟 KickShoes - A Modern E-Commerce Experience Built with Style, Usability, and Power

- KickShoes is more than just a product sales platform — it is a modern, customizable, and scalable e-commerce solution featuring a full user system and an admin panel.
- Designed with clean UI/UX principles and built using robust technologies, KickShoes offers a seamless shopping experience for customers and a powerful management interface for administrators.
- Whether you're an individual entrepreneur or a professional business looking for an extendable foundation, KickShoes provides a flexible and accessible solution for all.

# 🛠️ Technologies Used
- 🚀 Technology and 📌 Description
- React	Component-based UI development
- TypeScript	Type safety and reliable application structure
- Tailwind CSS	Modern, responsive styling utility classes
- React Query	Efficient API state and data management
- Formik + Yup	Powerful form handling and validation
- Axios	HTTP client for API requests
- React Router DOM	Routing and page navigation
- JWT	Secure authentication system
- React Icons	Icon set integration
- React Toastify	Toast notifications
- DOMPurify	XSS protection by sanitizing HTML content
